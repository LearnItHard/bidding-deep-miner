# 搜索策略详解

## 招投标项目搜索的特殊性

不同于通用研究搜索，招投标项目搜索有以下特点：

1. **信息高度分散** — 同一项目的招标公告、中标公告、合同公告、变更公告分散在不同页面
2. **平台搜索能力弱** — 大多数招投标平台搜索功能简陋，不支持高级搜索语法
3. **关键词匹配敏感** — 搜索词和公告标题的措辞差异可能导致漏检
4. **时间窗口有限** — 招标公告有公示期，过期可能下架

## 四渠道搜索策略

### 渠道1: 招投标平台（主渠道）

**搜索优先级**：国家级 → 省级 → 市级平台

**可用的平台搜索 URL 库**（来自 `bidding_miner/urls/`）：
- 使用 `bidding_miner.urls` 中的 `build_search_url()` 构建搜索 URL
- 然后用 `fetch_webpage` 抓取搜索结果页
- 解析搜索结果列表，提取项目链接

**搜索技巧**：
- 先用**完整项目名**搜索
- 如无结果，用**项目名核心词**（去掉"扩建工程"、"项目"等泛词）
- 如仍无结果，用**项目编号**搜索（编号匹配最精确）
- 搜索项目周边的关联项目（同一招标人、同一地区、同期项目）

**重要**：招投标平台多为动态页面，`fetch_webpage` 可能返回空。此时应：
1. 检查返回的 HTML 是否包含实际结果
2. 如有 JS 渲染问题，尝试用 `browser` 工具打开页面
3. 或构造平台的 API 搜索 URL（部分平台提供 JSON 接口）

### 渠道2: 通用搜索引擎（搜索引擎 URL 直抓）

**方法**：使用 DuckDuckGo HTML 版直抓（已验证可用）
- URL: `https://html.duckduckgo.com/html/`
- 用 `fetch_webpage` 抓取搜索结果
- 解析 `div.result` → `a.result__a`（标题+URL）+ `a.result__snippet`（摘要）

**搜索词组合策略**（按优先级尝试）：
1. `"{项目名}" {地点}` — 精确匹配
2. `{项目名} 工艺 技术方案` — 找技术方案
3. `{项目名} 中标 合同` — 找中标信息
4. `{项目名} 环评 可研` — 找前期文件
5. `{核心工艺词} {地点} 污水处理` — 反向查找同类项目

### 渠道3: 学术搜索（辅助验证）

**方法**：构造 Google Scholar 和 arXiv 搜索 URL
- Google Scholar: `https://scholar.google.com/scholar?q={query}&hl=zh-CN`
- arXiv: `https://arxiv.org/search/?query={query}`

**用途**：验证推断出的工艺在该领域是否主流、是否有最新研究支持

### 渠道4: 行业资讯（背景了解）

在通用搜索中额外搜索：
- `{项目名} 开工 竣工 通水`
- `{招标人名称} 项目 业绩`
- `{地区} 污水处理 规划`

## 迭代搜索策略

当置信度不足时（内环→外环决策为 deepen），按以下策略发起新一轮搜索：

1. **关键词扩展** — 用已发现的技术关键词缩小搜索范围
2. **反向查找** — 用推断出的工艺名 + 地区/招标人 搜索
3. **深度抓取** — 将第一轮发现的 URL 用 `fetch_webpage` 深入抓取全文
4. **平台切换** — 如果国家级平台无结果，下沉到省级平台

## 搜索结果去重与排序

- 同名项目可能在不同平台重复出现 → 按发布时间取最新
- 同一平台的多条公告（招标→变更→中标）→ 全部保留，按时间排序
- 不同来源的同一信息 → 在交叉验证阶段标记为"多源印证"
