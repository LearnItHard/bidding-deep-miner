# 证据可信度分级标准

## 分级体系

| 级别 | 来源类型 | 典型来源 | 权重 | 说明 |
|------|---------|---------|------|------|
| **P1** | 官方招标文件原文 | 招标公告中的"项目概况"、"技术规格"章节；招标文件PDF正文 | 最高 | 这是招标人的正式需求说明，直接权威 |
| **P2** | 技术审查文件 | 环评报告、可研报告、初步设计批复、施工图审查意见 | 高 | 经专家评审的技术文件，间接但高度可靠 |
| **P3** | 中标/合同公告 | 中标结果公告中的"工程内容"、"中标人"、"中标金额" | 中 | 确认了谁中标、做什么，但可能不含具体工艺 |
| **P4** | 行业报道与企业信息 | 中标企业官网的项目案例、行业媒体新闻、地方政务公开 | 中低 | 侧面印证，但可能有宣传夸大 |
| **P5** | 非官方信息 | 搜索引擎摘要、论坛讨论、百科、自媒体文章 | 最低 | 仅有线索价值，不可作为独立证据 |

## 证据可信度升级规则

一条证据可因以下原因升级可信度：
- **多源交叉印证** — 同一信息在 ≥2 个不同来源中出现 → +1 级（如 P4+P4 → P3 级）
- **权威来源背书** — P3 信息被 P1 或 P2 来源间接支持 → 升级
- **时效性加持** — 近期发布的公告比历史信息更可信

## 证据可信度降级规则

- **来源冲突** — 两个同级别来源信息矛盾 → 都降 1 级
- **信息过时** — 超过 2 年的信息 → 降 1 级（技术方案可能已更新）
- **来源不明** — 无法追溯到原始出处 → 直接归为 P5

## 交叉验证原则

1. **频率加权**: 在多源中反复出现的工艺名称，置信度更高
2. **来源权威加权**: P1(×5) > P2(×3) > P3(×2) > P4(×1) > P5(×0.5)
3. **独立性加分**: 两个完全独立的来源（不是互相引用）给出相同信息，更可靠
4. **矛盾处理**: 当证据矛盾时，优先采信可信度级别高的来源，但标注矛盾

## 置信度计算方法

```
置信度 = Σ(证据权重 × 来源权重) / Σ(最大可能权重)

其中:
- 证据权重: 每条证据指向某工艺的强度 (0-1)
- 来源权重: P1=1.0, P2=0.8, P3=0.6, P4=0.3, P5=0.1
- 如果多源一致指向同一结论，额外 +0.15

置信度 ≥ 0.7 → 高置信度，可以得出结论
置信度 0.4-0.7 → 中置信度，需要更多证据
置信度 < 0.4 → 低置信度，必须继续搜索
```
